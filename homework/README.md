###  Практическая работа за 18.09 пара номер 2

Задание: вам нужен один cross aplay, один out aplay, 5 методов классики и 3 окна со всеми методами

Первая таблица (STUDENT): содержит общую информацию ID и имя студента 
Вторая таблица (PROGRESS): содержит строки с оценками. У одного студента может быть 3, 5 или 10 оценок 

Буквы .s и .p это псевдонимы, сокращение от student и progress, нужны для названий таблиц (чтобы не писать названия длинные)

1. Мы сделали CROSS APLY, то есть нашли одну (TOP 1) самую высокую оценку благодаря сортировке ORDER BY p.MARK DESC и вывели её на экран 
<img width="843" height="937" alt="QWQQWэкрана 2026-09-18 135805" src="https://github.com/user-attachments/assets/d02daec4-0f13-480f-af16-7739ed43ccf2" />

2. Теперь сдделали OUTER APPLY как по примеру, он берёт всех студентов из STUDENT и пытается найти для каждого его лучшую оценку в таблице PROGRESS
<img width="903" height="1261" alt="IIUIYIUYэкрана 2026-09-18 140112" src="https://github.com/user-attachments/assets/7a6a4f77-f48a-49d7-84f8-42c9548c787d" />


Далее идут 5 примеров классики:

Метод 1. Обычный GROUP BY. Просто считает, сколько студентов учится в каждой группе. Строки схлопываются по номерам групп.

Метод 2. подзапрос в секции SELECT. Выводит список студентов, а рядышком прямо в SELECT считает количество оценок для каждого из таблицы PROGRESS

Метод 3. Группировка через JOIN (Соединение таблиц). Что делает: Мы берем таблицу с оценками, схлопываем её до среднего балла и добавляем через JOIN к именам студентов.

Метод 4. Группировка с фильтром HAVING (Проще некуда)Что делает: Группирует студентов по номерам групп и выводит только те группы, в которых сидит больше одного человека [рус.].

Метод 5. Группировка с ROLLUP (Итоги) - Считает студентов по группам (как Метод 1), но в самом-самом низу таблицы выведет отдельную строчку, где будет написано общее число студентов по всему университету.
