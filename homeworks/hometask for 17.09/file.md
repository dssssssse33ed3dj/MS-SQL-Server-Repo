
**Домашнее задание для лаб. номер 7:**
- Тема: Сравнительный анализ способов группировки данных в T-SQL (GROUP BY и оконная функция PARTITION BY).
- Описание задачи: Вам потребуется проанализировать способы групировки и сравнить их. В дз отправить результат сравнения через гитхаб

- Что было сделано:  Я написал и протестировал два запроса для расчета среднего балла студентов по учебным группам с целью сравнения способов агрегации. Первый запрос через GROUP BY «схлопнул» записи в одну строку на группу, скрыв детальную информацию о студентах и сделав бы VIEW немодифицируемым. Второй запрос с оконной функцией PARTITION BY сохранил исходную структуру таблицы, и 1 запросом вывести ФИО студента и показатели группы новой колонкой напротив каждой строки.
