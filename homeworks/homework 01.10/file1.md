### Домашняя работа от 01.10 - архитектура индексов

- Цель задачи: Изучить архитектуру индексов в T-SQL на основе профильной литературы и видеоматериалов, сформировав базу для оптимизации запросов.
- Описание задачи: Проанализировать внутреннее устройство индексов в SQL Server, используя материалы книг «Pro SQL Server Internals» (Дмитрий Короткевич) и «SQL Server Query Performance Tuning» (Грант Фритчи), а также обучающие видео по теме. Выделить ключевые концепции без лишней воды.
Что было сделано: Изучена структура B-Tree (B-дерево): Разобран принцип хранения данных в виде сбалансированного дерева, состоящего из корневого уровня (Root), промежуточных уровней (Intermediate) и листового уровня (Leaf).
  - Сравнены кластеризованные и некластеризованные индексы:
	- Кластеризованный (Clustered): Физически упорядочивает данные в таблице. Листовой уровень — это сами строки с данными. Может быть только один на таблицу.
	- Некластеризованный (Nonclustered): Хранится отдельно от таблицы. Листовой уровень содержит указатели на данные (RID в куче или ключ кластеризованного индекса).
- Рассмотрены кучи (Heaps): Изучена специфика таблиц без кластеризованного индекса, где данные хранятся неупорядоченно, а поиск происходит через сканирование всей таблицы (Table Scan), если нет подходящих некластеризованных индексов.
- Выделены факторы производительности: Определено влияние плотности данных, фрагментации индексов и операций выделения страниц (Page Splits) на общую скорость выполнения T-SQL запросов.
