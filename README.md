**Microsoft SQL Server** - СУБД по клиент-серверной архитектуре: клиент шлет запросы на T-SQL, сервер их выполняет.
!!! База данных  состоит из файлов данных и журнала транзакций. Работа также ведется через SSMS.

> **Серверы являются экземплярами!** (это реализация шаблона, например, класса или структуры)
 
Установили *SQL Server Management. Для подключения к sql server Management вводим имя и строку подключения 

> эта программа делиться на этажи - сервера, отель - компьютер и номера - БД

#### Окно в SQL Server Management Studio делиться на:
* Оконное меню - набор команд для управления сервером
* Панель инструментов - содержит кнопки для операций 
* Панель «Object Explorer» - обозреватель   объектов
* Рабочая область - там все действия БД
<img width="685" height="590" alt="image" src="https://github.com/user-attachments/assets/1a383fe1-d926-4213-9415-df12d27dab0b" />

#### Типы данных:
Типы данных:

1. Числовые: TINYINT, SMALLINT, INT, BIGINT (целые), DECIMAL, REAL, FLOAT (дробные).

2. Строковые: CHAR и VARCHAR (ASCII), NCHAR и NVARCHAR (Unicode). Длина указывается в скобках.

3. Специальные: BIT (логический 0/1), DATETIME (дата/время), MONEY (денежный).


У ДБ есть расширения формата `.mdf`, `.ldf`.

**Метаданные** - это данные о действиях пользователя и каким пользователем было совершено действие 

В `Database` --> `System database` хранится ветка Системные БД - `master`, `model`, `msdb`, `tempdb`

Настройка ключей и таблиц: Базы и таблицы создаются в UI (ввод данных доступен через «Изменить первые 200 строк»). Если первичному ключу  нужно автоматическое заполнение числами, для него включается «Спецификация идентификатора», где задается начальное значение и шаг.

SQL Server Management Studio (SSMS) – инструмент администрирования для для формирования структуры БД и выполнения запросов и т.п

Установили **SQL Server 2025** в начале пары и соединились с ядром СУБД *SQL Server Management*. Далее создали базу данных через `CREATE DATABASE`. После подключения программа откроет содержимое сервера:
<img width="755" height="820" alt="image" src="https://github.com/user-attachments/assets/19621f4a-b702-4002-9837-46ce3e35d176" />

В состав БД входят таблицы (хранят данные), представления (возвращают данные в виде таблицы), хранимые процедуры (выполняют код по отношению к БД), и т.д.

Системные БД:
master: хранит учетные записи, роли, настройки и информацию обо всех базах на сервере.

model: шаблон для создания БД других.

msdb: содержит информацию о резервном копировании и задачах планировщика.

tempdb: хранилище временных объектов, полностью пересоздается при перезапуске сервера.

После ПКМ по Tables откроется **дизайнер таблицы**, состоящий из имя столбца, типа данных его и также может ли отсутствовать занчение и столбца (null). Там в нем можно выставить Primary key, редактировать первые 200 строк и т.п.
<img width="1568" height="975" alt="image" src="https://github.com/user-attachments/assets/1b395bdb-cb0b-4477-afdb-7b71f32f3c7f" />

БД можно создать через Обозреватель объектов или T-SQL командой CREATE DATABASE название_бд. Удаление — командой DROP DATABASE название_бд. Если есть готовый файл базы (.mdf), его можно прикрепить скриптом: CREATE DATABASE... ON PRIMARY (FILENAME='путь_к_файлу') FOR ATTACH;.

Запросы выполняются через F5 или «Execute» (или F5). Базовый запрос на все данные - SELECT * FROM название_таблицы.
