**Microsoft SQL Server** - бд по клиент-серверной архитектуре. (когда клиент отправляет запрос на языке Т-SQL серверной машине, СЕРВЕР принимает обращение с требованием выполнить действие и выполняет задачу, а машина отправляет выполненный запрос)

> **Серверы являются экземплярами!** (это реализация шаблона, например, класса или структуры)
 
Установили *SQL Server Management*  
Для подключения к sql server managment вводим имя и строку подключения 

> эта программа делиться на этажи - сервера, отель - компьютер и номера - БД

#### Окно в SQL Server Management Studio делиться на:
* Оконное меню 
* Панель инструментов
* Панель «Object Explorer» 
* Рабочая область

В папке БД создать БД ПКМ, она состоит из двух данных (журнал транзакций и логирование)

#### Типы данных:
* **целочисленные типы** 
  - `tinyint`
  - `smallint`
  - `bigint`

* **для дробных чисел**
  - `real`, `float` and `decimal`

* **специальные типы данных:**
  - `bit`, `image`

* **типы данных:** `datetime`, `smallDatetime`

* **денежные типы данныъ:** `money` / `smallmoney`

* **спец символы:** `char` , `varchar`, `nvarchar`

У ДБ есть расширения формата `.mdf`, `.ldf`.

**Метаданные** - это данные о действиях пользователя и каким пользователем было совершено действие 

В `Database` --> `System database` хранится ветка Системные БД - `master`, `model`, `msdb`, `tempdb`
